# warp

warp is a cli tool to improve the navigation between your projects

### HOW TO INSTALL

1. change permissions for leap.sh: `chmod +X leap.sh`
2. Move leap file: `sudo mv ./leap.sh /usr/local/bin/leap`
3. move `leap.sh` to folder created in step 1.
4. create folder for persistent memory: `mkdir /Users/ihorlysak/warp`
5. add file for gates list: `touch /Users/ihorlysak/warp/gates.txt`
6. add approperiate permissions to files/folders for all of this to work
